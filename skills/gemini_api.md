# skill: gemini_api — Gemini API使用ルール

## モデル名
- テキスト生成：`gemini-2.5-flash`
- 画像生成：`gemini-2.5-flash-image`

## 呼び出し関数
`api_handlers.py` の `_call_gemini(prompt, retries=2)` を使う。
新しいGemini呼び出しを直接書かず、必ずこの関数を経由する。

## プロンプト設計ルール
- 日本語出力が必要なら「日本語で出力」を明記
- 文字数制限は「〜文字以内」と数値で指定
- 「投稿文のみ出力（説明・前置き不要）」を必ず末尾に追加
- コンテキスト（魂）がある場合は冒頭に挿入

## エラー対処
- 429エラー：自動リトライ（sleepあり）
- 空文字列返却：フォールバック値を設定する
