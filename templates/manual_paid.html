1X Post Generatorとは

X（Twitter）への投稿をAIで自動生成・投稿できるツールです。

  • ニュースを選んで意見を書くだけでAIが投稿文を3パターン生成
  • 画像も3種類自動生成（Gemini AIによる高品質画像）
  • 予約投稿で指定時刻に自動投稿
  • 【有料限定】複数Xアカウントの登録・切り替え投稿

2アクセス方法

  • ins-japan.comの会員ページからアクセス
  • ブラウザに自動で記録されます（毎回ログイン不要）

3短文投稿の使い方

  1. 「💬 短文投稿」タブを選ぶ
  2. テキストを入力して「🤖 AI生成」で3パターン生成
  3. 気に入ったパターンをクリックして選択
  4. 「🖼️ 画像生成（3種類）」で3種類の画像を生成
  5. 画像を1枚選んで「📤 選択した画像でX投稿」をクリック

4ニュース投稿の使い方

  1. 「📰 ニュース投稿」タブを選ぶ
  2. ニュースソースを選んで「📰 ニュース取得」をクリック
  3. 気になる記事を選ぶ
  4. 自分の意見を入力して「🤖 AI生成」をクリック
  5. 投稿パターンを選んで画像生成・投稿

5予約投稿の使い方

  1. 投稿ボタンの上の「⏰ 予約時刻」に日時を入力
  2. 空欄のまま投稿 → 今すぐ投稿
  3. 日時を入力して投稿 → 指定時刻に自動投稿

6よくある質問

  • AI生成に時間がかかる：1〜2分程度かかることがあります。そのままお待ちください。
  • 画像生成に失敗する：Gemini APIの一時的な制限の場合があります。再度お試しください。
  • 投稿に失敗する：X APIの制限の可能性があります。時間をおいてお試しください。

7プレミアムコードの認証方法

有料会員登録完了時に自動送信されるメールにプレミアムコードが記載されています。

  1. 「⚙️ 設定」タブを開く
  2. 有料会員登録時にメールで届いたプレミアムコードを入力
  3. 「🔑 認証する」をクリック
  4. 「✅ プレミアムプラン」と表示されれば認証完了

プレミアムコードの認証状態はブラウザのlocalStorageに保存されます。ブラウザのキャッシュをクリアした場合は再認証が必要です。

8X APIキーの取得方法

  1. https://developer.x.com にアクセス
  2. 「Developer Portal」にXアカウントでログイン
  3. 「Projects & Apps」→「New App」で新しいアプリを作成
  4. 「Keys and tokens」タブで以下の4つを取得：
  • ① API Key（Consumer Key）
  • ② API Key Secret（Consumer Secret）
  • ③ Access Token
  • ④ Access Token Secret

アクセス権限は必ず「Read and Write」に設定してください。「Read only」では投稿できません。

X Developer Portalの登録は無料です。ただし、利用規約への同意が必要です。

9複数アカウントの登録方法

  1. 「⚙️ 設定」タブを開く
  2. 「➕ アカウントを追加」セクションへスクロール
  3. アカウント名を入力（例：メインアカウント・副業アカウント）
  4. 取得した4つのAPIキーをそれぞれのフィールドに貼り付け
  5. 「💾 アカウントを保存」をクリック
  6. 複数アカウントを繰り返し登録できます

APIキーはブラウザのlocalStorageに保存されます。サーバーには送信されません。
ブラウザのキャッシュをクリアするとアカウント情報が消えます（再登録が必要）。

10投稿アカウントの切り替え方法

  1. 2つ以上のアカウントを登録すると、投稿セクションに「📱 投稿アカウント」が表示されます
  2. プルダウンから投稿したいアカウントを選択
  3. 「デフォルトアカウント（サービス設定）」はサービス標準アカウント
  4. 投稿ごとに異なるアカウントを選択可能

アカウント選択はセッション内で有効です。ページを再読み込みしても選択したアカウントは保持されます。

11セキュリティについて

  • APIキーはあなたのブラウザのlocalStorageにのみ保存されます
  • サーバーへの送信は投稿時のみ（HTTPS暗号化通信）
  • サーバー側にAPIキーは記録・保存されません

注意事項：
・APIキーは他人に見せないでください
・共有PCでは使用しないでください
・ブラウザのキャッシュをクリアするとアカウント情報が消えます（再登録が必要）
・不正アクセスが疑われる場合はX Developer Portalでキーを再生成してください
